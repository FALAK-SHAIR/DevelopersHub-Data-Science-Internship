# Task 1: Term Deposit Subscription Prediction (Bank Marketing)

**DevelopersHub Corporation — Data Science & Analytics Internship (Advanced Task Set)**

## Objective
Predict whether a bank customer will subscribe to a term deposit as a result of a phone-based marketing campaign, and explain individual model predictions using SHAP (Explainable AI).

## Dataset
- **Source:** Bank Marketing Dataset, UCI Machine Learning Repository (Moro, Cortez & Rita, 2014)
- **File used:** `bank-additional-full.csv` — 41,188 records, 20 input features + target `y` (yes/no)

## Approach
1. **EDA:** Explored target imbalance (~11.3% "yes"), age/job/education/month vs subscription rate, and correlation among macro-economic numeric features.
2. **Preprocessing:** No missing values (dataset uses `"unknown"` category instead); target mapped to binary; categorical features properly encoded using one-hot encoding (avoids imposing false ordinal relationships).
3. **Modeling:** Trained a **Logistic Regression** (baseline, with feature scaling) and a **Random Forest** classifier, both with `class_weight='balanced'` to handle class imbalance.
4. **Evaluation:** Confusion matrices, classification reports, F1-score, and ROC-AUC/ROC curves for both models.
5. **Explainability (XAI):** Used **SHAP TreeExplainer** on the Random Forest to generate:
   - A global summary plot (top drivers across the model)
   - Individual waterfall plots explaining 5 specific customer predictions (true positives, true negatives, and a false negative)

## Results

| Model | F1-Score | ROC-AUC |
|---|---|---|
| Logistic Regression | 0.604 | 0.944 |
| Random Forest | 0.615 | 0.949 |

- Random Forest slightly outperformed Logistic Regression on both metrics, indicating it captures non-linear interactions between features (e.g., job × education × campaign month) more effectively.
- Both models achieve high recall on the "yes" class (86–94%) after balancing, at the cost of precision — appropriate for a marketing use case where missing a likely subscriber is more costly than an extra call.

## Key Insights
- Call `duration`, macro-economic indicators (`euribor3m`, `nr.employed`, `emp.var.rate`), previous campaign outcome (`poutcome`), and `pdays` are the strongest predictors.
- Students, retirees, and more highly educated customers subscribe at notably higher rates.
- Subscription rate varies significantly by contact month, suggesting campaign timing matters.
- `duration` is only known after a call ends — a model meant to *decide who to call in advance* should be retrained without it; the current model (with `duration` included, as per the dataset's own documentation) is best used for benchmarking/post-call analysis.
